## Declaration Statements

1. **Authorized Environment:** I confirm that all testing and execution of this keylogger simulation was conducted exclusively on an owned device or a device for which explicit consent was granted.
2. **Scope Limitation:** I confirm that the simulation operates strictly within its own application graphical interface and does not capture system-wide keystrokes or monitor external applications.
3. **Data Protection & Privacy:** I confirm that only non-sensitive, dummy test data was used during execution. No real passwords, credentials, or personal information were recorded or processed.
4. **Local-Only Operation:** I confirm that captured event records were stored locally using authenticated encryption (Fernet) and were never transmitted across a network or external system.
5. **Ethical Integrity:** I acknowledge that covert keylogging, unauthorized system monitoring, and data exfiltration are illegal and unethical. This project is created solely for educational and security demonstration purposes.
